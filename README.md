# YouTube Trend Analysis

유튜브 인기 영상의 제목·태그·댓글을 분석하여 카테고리별 트렌드 키워드, 순위 변동, 연관 키워드, 관련 영상을 제공하는 데이터 분석 프로젝트입니다.

단순 조회수 순위에 의존하지 않고, 댓글에서 반복적으로 언급되는 키워드, 텍스트 내 중요도, 영상 반응 지표를 결합해 사용자가 실제로 반응하는 주제를 찾는 것을 목표로 했습니다.

> 이 저장소는 프로젝트 당시 구축한 분석 파이프라인과 서비스 프로토타입에서, 핵심 분석 로직을 추출해 정리한 포트폴리오 버전입니다. API 키, DB 인스턴스, 운영 수집 데이터는 포함하지 않습니다.

## 문제 정의

영상 조회수가 높다고 해서 시청자가 실제로 어떤 주제에 관심을 가졌는지 알 수는 없습니다. 특히 댓글에는 제목에 충분히 드러나지 않는 인물, 사건, 반응, 세부 주제가 담깁니다.

> 인기 영상과 댓글에서 주목받는 주제를 어떻게 추출하고, 단순 언급량을 넘어 의미 있는 키워드 순위로 만들 수 있을까?

## 담당 역할

분석 파이프라인과 키워드 랭킹 방법론의 기획·개발을 담당했습니다.

- YouTube Data API로 수집한 영상 메타데이터와 댓글 데이터의 전처리 기준 설계
- URL, HTML, 이모지, 불필요한 기호 제거 및 카테고리별 표현 정규화
- Kiwi 한국어 형태소 분석기를 활용한 키워드 후보 추출 및 불용어 처리
- 빈도, TextRank, TF-IDF, KRWordRank를 결합한 영상별 키워드 점수 설계
- 카테고리·기간 단위 집계 및 순위 변동 로직 설계
- 댓글 N-gram과 PMI를 활용한 연관 키워드 추출 구현

프런트엔드와 API 서버는 분석 결과를 확인하고 제공하기 위한 서비스 프로토타입으로 구성했습니다.

## 주요 기능

- **카테고리별 키워드 랭킹**: 뉴스·정치, 음악, 스포츠, 게임, 과학·기술의 일간·주간·월간 순위
- **순위 변동**: 이전 기간과 비교한 상승·하락·신규 진입·랭크 아웃 표시
- **키워드 상세 분석**: 추이, 성장 지표, 관련 영상, 반응 지표 제공
- **연관 키워드**: 댓글 N-gram 동시 출현과 PMI 기반 키워드 연관성 계산
- **콘텐츠 기획 지원**: 분석 주제와 연관 키워드로 제목·스크립트 초안을 생성하는 UI

## 분석 파이프라인

    YouTube Data API
      └─ 인기 영상, 댓글, 메타데이터 수집
           ↓
    텍스트 전처리 및 표현 정규화
      └─ HTML / URL / 이모지 / 노이즈 제거, 카테고리별 별칭 통합
           ↓
    형태소 분석 및 키워드 후보 추출
      └─ Kiwi + 불용어 처리 → 고유명사·외국어 중심 토큰
           ↓
    영상별 키워드 점수화
      └─ 빈도 점수 + TextRank + TF-IDF / KRWordRank
           ↓
    분석 결과 저장
      └─ 영상별 combined_score 생성
           ↓
    기간·카테고리별 집계 및 순위 비교
      └─ 일간 / 주간 / 월간 랭킹과 이전 기간 대비 변동
           ↓
    Express API → Vue UI

## 랭킹 산정 방법

### 1. 텍스트 전처리와 후보 키워드 선정

댓글을 원문 그대로 분석하지 않았습니다. 분석에 불필요한 요소를 제거하고, 같은 대상을 가리키는 다양한 표현을 정규화한 뒤 키워드 후보를 뽑았습니다.

- HTML 태그, URL, HTML entity, 이모지 제거
- 영문 소문자화
- 카테고리별 별칭과 오탈자 정규화
  - 예: 정치 인물의 별칭, 음악 그룹의 한글·영문·약칭
- 공통 불용어와 빈도가 높은 일반 표현 제거
- 두 글자 이상인 고유명사(NNP)와 외국어(SL)를 중심으로 후보 토큰 선정
- 제목, 태그, 댓글에서 나온 후보를 서로 다른 신호로 분리

### 2. 세 가지 보완적 신호

키워드는 여러 이유로 중요할 수 있습니다. 제목에 직접 등장할 수도 있고, 댓글에서 반복 언급될 수도 있으며, 댓글 문맥의 중심에 있거나 카테고리 내에서 특징적인 단어일 수도 있습니다. 하나의 지표에 의존하지 않도록 세 신호를 결합했습니다.

| 신호 | 입력 데이터 | 반영하는 의미 |
| --- | --- | --- |
| 출처 기반 빈도 | 제목 명사, 태그, 댓글 명사 | 영상의 직접적 주제와 댓글 언급량 |
| TextRank | 댓글 명사로 만든 가중 동시 출현 그래프 | 댓글 문맥에서의 중심성 |
| TF-IDF × KRWordRank | 같은 카테고리 영상의 전체 댓글 코퍼스 | 영상별 차별성과 카테고리 내 중요도 |

### 3. 출처 기반 빈도 점수

제목에 등장한 키워드는 영상의 주제를 직접 나타내는 강한 신호이므로, 댓글에 한 번 등장한 키워드보다 높은 가중치를 부여했습니다.

| 출처 | 구현 규칙 | 의도 |
| --- | --- | --- |
| 제목 명사 | 30점 부여 | 영상이 직접 다루는 주제 반영 |
| 태그 | 10점 부여 | 제목 신호를 보완하는 구조화 메타데이터 반영 |
| 댓글 명사 | 등장할 때마다 0.1점 누적 | 반복되는 시청자 반응을 반영하되 댓글량이 제목 신호를 압도하지 않게 조정 |

키워드 k의 영상 v에서의 빈도 점수는 아래와 같습니다.

    frequency_score(v, k)
    = title_weight(v, k)
    + tag_weight(v, k)
    + 0.1 × comment_occurrences(v, k)

제목과 태그는 해당 출처에 존재하는지에 따른 가중치이고, 댓글 점수는 반복 등장 횟수에 따라 증가합니다.

### 4. TextRank 점수

TextRank는 키워드가 단순히 많이 등장했는지보다 댓글 문맥에서 얼마나 중심적인지를 반영합니다.

1. 순서가 있는 댓글 명사 목록으로 무방향 가중치 그래프를 만듭니다.
2. 4개 토큰 크기의 슬라이딩 윈도우 안에서 함께 등장한 서로 다른 단어를 연결합니다.
3. 같은 단어 쌍이 다시 등장하면 간선 가중치를 증가시킵니다.
4. 가중치 PageRank로 각 키워드의 문맥 중심성을 계산합니다.
5. 상위 50개 키워드의 순위를 50점부터 1점으로 변환합니다.

    textrank_score(v, k) = 50 - rank(k)

이 방식은 중요한 이웃 키워드와 많이 연결된 단어를 높게 평가합니다.

### 5. TF-IDF와 KRWordRank 점수

영상별 댓글 명사를 하나의 문서로 만들고, 같은 카테고리의 모든 영상 댓글을 하나의 코퍼스로 사용했습니다.

1. 영상별 모든 후보 단어의 TF-IDF를 계산합니다.
2. 카테고리 코퍼스에 KRWordRank를 적용합니다.
   - 최소 출현 수 1, 최대 단어 길이 10, 감쇠 계수 0.85, 반복 10회
3. 각 영상·키워드 쌍에 대해 TF-IDF와 KRWordRank 값을 곱합니다.
4. 곱이 큰 순서대로 상위 50개를 골라 50점부터 1점의 순위 점수로 변환합니다.

    importance(v, k) = tfidf(v, k) × krwordrank(k)
    tfidf_krwordrank_score(v, k) = 50 - rank_by_importance(k)

TF-IDF는 여러 영상에 광범위하게 나타나는 흔한 단어의 영향을 낮춥니다. KRWordRank는 카테고리 전체에서 단어의 중요도를 반영합니다. 실제 곱 값 대신 순위 점수를 저장해 TextRank 점수와 비교 가능한 스케일을 유지했습니다.

### 6. 영상별 최종 점수

세 신호는 동일 가중치로 더해 영상별 최종 키워드 점수인 combined_score가 됩니다.

    combined_score(v, k)
    = frequency_score(v, k)
    + textrank_score(v, k)
    + tfidf_krwordrank_score(v, k)

따라서 하나의 키워드는 제목·태그의 직접적 근거, 댓글에서의 반복 언급, 댓글 문맥 중심성, 카테고리 내 상대적 중요도를 복합적으로 반영해 높은 점수를 얻습니다.

### 7. 기간별 랭킹과 순위 변동

선택한 기간과 카테고리에 포함된 모든 영상의 combined_score를 키워드별로 합산해 최종 랭킹을 계산합니다.

    period_score(category, k)
    = Σ combined_score(v, k)
      for every selected video v in the category and period

현재 기간 Top 30과 이전 비교 기간 Top 30을 비교해 다음 상태를 표시합니다.

- rising: 순위 상승
- falling: 순위 하락
- unchanged: 순위 유지
- new: 신규 진입
- ranked_out: 랭크 아웃

## 연관 키워드 산정

연관 키워드는 최근 댓글 토큰의 N-gram 동시 출현을 사용해 계산합니다.

1. 댓글 토큰으로 연속 N-gram을 생성합니다.
2. 대상 키워드와 같은 N-gram에 등장한 다른 단어를 후보로 모읍니다.
3. 키워드 등장, 후보 단어 등장, 동시 출현 확률로 PMI를 계산합니다.
4. PMI와 동시 출현 수를 곱해 연관 강도와 빈도를 함께 반영합니다.

    related_score(k, w)
    = PMI(k, w) × co_occurrence_count(k, w)

PMI만 사용하면 드물게 한 번 함께 등장한 단어가 과대평가될 수 있으므로, 최소 동시 출현 횟수를 설정해 노이즈를 줄였습니다.
